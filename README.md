# 점수 계산

점수를 배열에 저장하고 반복문으로 평균, 최고점, 최저점을 구하는 C 프로그램입니다.

## 실행

이 폴더에서 컴파일한 뒤 실행합니다.

```sh
gcc scores.c -o scores
./scores
```

Windows에서는 Visual Studio 개발자 명령 프롬프트에서 실행할 수 있습니다.

```bat
cl /nologo /W4 /WX /D_CRT_SECURE_NO_WARNINGS scores.c /Fe:scores.exe
scores.exe
```

먼저 점수 개수를 입력하고, 점수를 하나씩 입력합니다. 숫자 뒤에 공백이나 다른 문자를 붙이지 않고 바로 Enter를 누릅니다.
개수는 1~100개, 점수는 0~100 사이의 정수만 입력합니다.
잘못된 값을 입력하면 안내 문구를 출력하고 종료합니다.

`scanf("%3d%c", ...)`는 최대 세 자리의 숫자와 그 뒤의 문자 하나를 읽습니다. 뒤의 문자가 줄바꿈인지 확인해 `50.5`, `50abc`, `1000` 같은 입력을 걸러냅니다.

예를 들어 개수를 `5`, 점수를 `45`, `60`, `75`, `90`, `100`으로 입력하면 결과는 다음과 같습니다.

```text
Average: 74.00
Max: 100
Min: 45
```

`sample-scores.txt`의 첫 줄은 개수, 나머지 줄은 점수입니다. 마지막 점수 뒤에도 줄바꿈이 있어야 합니다. Linux/macOS에서는 `./scores < sample-scores.txt`, Windows 명령 프롬프트에서는 `scores.exe < sample-scores.txt`로 실행할 수 있습니다.

## 직접 확인하기

각 항목마다 프로그램을 다시 실행하고, 숫자는 하나씩 입력합니다.

| 개수 | 점수 | 예상 결과 |
| --- | --- | --- |
| 5 | 45, 60, 75, 90, 100 | 평균 74.00, 최고 100, 최저 45 |
| 1 | 80 | 평균 80.00, 최고 80, 최저 80 |
| 2 | 0, 100 | 평균 50.00, 최고 100, 최저 0 |
| 3 | 50, 50, 51 | 평균 50.33, 최고 51, 최저 50 |
| 0 | 입력 안 함 | 개수 오류 안내 후 종료 |
| 1 | 101 | 점수 오류 안내 후 종료 |
| 1 | abc | 점수 오류 안내 후 종료 |
